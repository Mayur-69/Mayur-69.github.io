01 / Generative AI

AI Search Visibility & Citation Analytics

LLM data pipeline, NLP & ML

When B2B buyers ask an AI assistant for product recommendations, which brands get mentioned, and what makes a web page get cited?

  • Built an end-to-end pipeline that queries Gemini with Google Search grounding across 150 buyer-intent prompts in 3 B2B SaaS categories (45 brands with aliases), storing answers, raw JSON and resolved citation URLs in PostgreSQL via SQLAlchemy.
  • Extracted brand mentions, order of appearance and sentiment with Gemini structured output validated by Pydantic schemas, normalized against brand aliases and checked against a hand-labeled sample.
  • Scraped cited and top-ranked pages with httpx + trafilatura (Playwright fallback for JS-rendered sites) and engineered content features: structure, FAQ and JSON-LD markup, freshness, domain type and prompt-to-page semantic similarity using sentence-transformers.
  • Compared search-rank-only, content-only and combined logistic regression models with prompt-grouped cross-validation (GroupKFold) to prevent leakage; reported share of voice, average rank and top cited domains per category.

02 / Forecasting

NYC Taxi Demand Forecasting

Full-stack ML & data engineering

How can a ride-hailing platform pre-position drivers using hourly, zone-level demand forecasts?

  • Engineered 27 calendar, lag, rolling and weather features; trained an XGBoost model that cut RMSE from 374.6 to 129.3 pickups/hour on a time-based 7-day holdout, surfaced in a Streamlit dashboard.
  • Built a modular 6-stage ETL pipeline ingesting 12.7M+ raw NYC taxi trips (Parquet) and hourly weather from the Open-Meteo REST API into a 14,880-row zone-by-hour dataset for the top 20 zones.
  • Enforced schema checks and removed malformed timestamps, invalid zone IDs and out-of-window dates — 12.74M raw rows down to 12.42M clean — with row counts logged at every filter.
  • Designed for reliable re-runs: explicit dtypes (~1.2 GB memory), Parquet caching, retry-with-backoff, rotating logs and 38 passing unit and integration tests.

03 / Sports analytics

IPL Analytics Platform

ML, SQL & data applications

What distinguishes successful teams and players, and can live match state predict the result?

  • Trained a logistic regression win-probability model on 72,000+ rows (ROC-AUC 0.79 on a held-out season) and built composite z-score player rankings, served in an interactive Streamlit what-if simulator.
  • Designed a relational SQLite schema for 636 matches and 150,000+ ball-by-ball records — composite primary key, cascading foreign keys, 12 indexes and a view tagging every delivery by match phase.
  • Wrote 10 analytical SQL queries (CTEs, joins, conditional aggregation) covering toss-to-win conversion, chasing success, venue scoring and phase-wise rates, exported to a 4-page Power BI report with DAX measures.
  • Built a one-command ingestion pipeline with validated config (Pydantic), rotating logs, Parquet caches and a pytest suite.

04 / Markets

NSE Sector Intelligence

Data engineering & analytics platform

How do NSE sectors compare on risk-adjusted returns, and how does a custom portfolio track versus NIFTY 50?

  • Built an automated ingestion layer bulk-downloading 5 years of daily prices for 52 NSE equities across 9 sectors, with per-ticker retry fallback and automatic exclusion of tickers missing over 20% of trading days.
  • Computed CAGR, volatility, Sharpe, Sortino, Calmar, max drawdown, beta and VaR/CVaR per stock in a 5-page Streamlit app.
  • Added a portfolio tracker — JSON import/export, P&L, sector allocation — benchmarked against NIFTY 50, with a 1-hour cached refresh and a JSON-configured ticker universe.
